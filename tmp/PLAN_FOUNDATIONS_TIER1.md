## ESTRATEGIA L1 FOUNDATIONS

### Proyecto Integrador Transversal

**"Sistema de gestión de tareas desde terminal (CLI)"**

Demuestra TODAS las capas a lo largo de 12 módulos:
- **Módulo 0:** Hardware, procesos, ejecución (concepto)
- **Módulo 1:** Rutas, carpetas (guardar tareas)
- **Módulo 2:** Variables (estado de tarea)
- **Módulo 3:** Entrada/Salida (comando `tarea add`, `tarea list`)
- **Módulo 4:** Control de flujo (si tarea completada, marcar)
- **Módulo 5:** Funciones (cada comando es una función)
- **Módulo 6:** Errores (qué pasa si archivo no existe)
- **Módulo 7:** Módulos (organizar código)
- **Módulo 8:** Testing (probar cada función)
- **Módulo 9-11:** Avanzados (persistencia real, config)

### Implementación L1: 50 temas × 4 cambios mínimos

Cada tema necesita:

1. **Paso 2:** Conectar al proyecto "Sistema de gestión de tareas"
   ```
   # ANTES
   #### Paso 2 · Contexto y caso real
   En un caso real...
   
   # DESPUÉS
   #### Paso 2 · Contexto y caso real
   El proyecto integrador Fundamentos que vas a construir es: 
   un sistema de gestión de tareas desde terminal (CLI).
   En un caso real...
   ```

2. **Paso 4:** Mencionar el archivo/ruta real del proyecto
   ```
   # Ejemplo en Módulo 1
   mkdir proyectos/tarea-cli
   ```

3. **Paso 6:** Práctica dentro del contexto del proyecto
   ```
   # ANTES: "crea una carpeta"
   # DESPUÉS: "crea la carpeta del proyecto de tareas"
   ```

4. **Paso 7:** Cierre conecta con siguiente módulo
   ```
   "Siguiente: usar variables para guardar estado de tarea"
   ```
