# Laboratorio de electrónica e IoT

17 modelos originales de Python y una comprobación algebraica del ejercicio de cuatro diodos, sin dependencias externas. Desde la raíz ejecuta `python3 examples/electronics/circuitos.py`. Cada archivo corresponde a un tema de Fundamentos, módulo 12, donde están explicación, salida esperada, fallo deliberado, práctica y límites.

Son modelos didácticos, no firmware ni validación de hardware. La teoría avanzada, montaje, estabilidad formal y certificación industrial requieren estudio y evidencia adicionales.
