# Streaming de Server Components

Node 24 LTS. Desde esta carpeta: `npm ci`, `npm run build`, `npm start`. Abre http://127.0.0.1:3000/envios y /envios?empty=1. Datos ficticios locales, sin base de datos ni secretos. El historial demora 1200 ms para hacer observable el límite Suspense.

Este es el laboratorio del tema 1. Los temas de autenticación y persistencia requieren incorporar sus propias dependencias, esquema y sesión verificada; este ejemplo público no implementa login ni autoriza operaciones de negocio. No uses una cookie sin validación como identidad.
