Az

Microsoft Azure

La plataforma cloud de Microsoft. Dominante en empresas que ya usan Office 365 y Active Directory. Muy fuerte en entornos híbridos (on-premises + cloud) y en IA empresarial con Azure OpenAI.

Los conceptos que aprendes en AWS con Floci se transfieren directamente a Azure. Cada servicio que practicas tiene un equivalente funcional. Lo que cambia es el nombre y algunos detalles de API.

G

Google Cloud Platform (GCP)

La infraestructura de Google al alcance de todos. Líder en analítica de datos (BigQuery), Kubernetes (GKE fue su origen) e inteligencia artificial generativa (Vertex AI y Gemini API).

El modelo mental de colas, cómputo sin servidor y almacenamiento de objetos es idéntico en las tres nubes. Después de dominar AWS con Floci, aprender GCP es principalmente aprender nuevos nombres y convenciones de CLI.

Almacenamiento base

S3 para archivos, SQS para colas, DynamoDB para datos. Son los cimientos de casi toda aplicación en la nube.

API con Lambda

Lambda ejecuta la lógica, API Gateway la expone como HTTP. CloudWatch registra todo lo que pasa.
