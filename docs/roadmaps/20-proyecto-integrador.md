# Bloque 20: Proyecto integrador RutaFlow

Este bloque contiene 1 roadmaps independientes. Cada roadmap avanza en 30 pasos, desde cero hasta una evidencia de nivel avanzado; no presupone experiencia previa en el tema.

Los pasos 1–10 construyen fundamentos, 11–20 desarrollan práctica y diagnóstico, y 21–30 integran el tema en un resultado más cercano al trabajo profesional. Marca cada casilla solo cuando puedas mostrar la evidencia indicada.

## Tema 53: RutaFlow: plataforma logística IoT

**Meta:** demo con contrato, pruebas, trazas, modelo geoespacial y escena arquitectónica

**Contexto de práctica:** seguir una entrega desde un sensor/móvil hasta el cliente con trazabilidad

**Conocimientos que conecta:** los 19 bloques anteriores; integrar por cortes verticales con hipótesis verificables

### Pasos 1–10: nivel Principiante

- [ ] **Paso 1.** Describe el problema de industria «seguir una entrega desde un sensor/móvil hasta el cliente con trazabilidad» y quién recibe valor de resolverlo.
- [ ] **Paso 2.** Escribe el resultado experto observable: demo con contrato, pruebas, trazas, modelo geoespacial y escena arquitectónica.
- [ ] **Paso 3.** Enumera lo que ya sabes y los prerrequisitos mínimos para estudiar rutaflow: plataforma logística iot.
- [ ] **Paso 4.** Define un glosario propio para las piezas de Flutter, Spring Boot, MySQL espacial, Kafka, JWT, Socket.IO, QA Postman/Newman/Jenkins, PostgreSQL, Docker/K8s/CI/IaC/LocalStack, Angular Signals; Repository, Observer, Strategy, Saga, Outbox y API Gateway.
- [ ] **Paso 5.** Dibuja el modelo, flujo o sistema físico de Flutter, Spring Boot, MySQL espacial, Kafka, JWT, Socket.IO, QA Postman/Newman/Jenkins, PostgreSQL, Docker/K8s/CI/IaC/LocalStack, Angular Signals; Repository, Observer, Strategy, Saga, Outbox y API Gateway antes de memorizar términos.
- [ ] **Paso 6.** Prepara repositorio RutaFlow, Docker Compose y emuladores locales; registra versión, comandos y una forma segura de limpiar el laboratorio.
- [ ] **Paso 7.** Encuentra en examples/rutaflow/README.md y documentación oficial citada en cada bloque una explicación oficial y anota qué conceptos confirma.
- [ ] **Paso 8.** Traza un caso exitoso de «seguir una entrega desde un sensor/móvil hasta el cliente con trazabilidad» desde la entrada hasta el resultado.
- [ ] **Paso 9.** Resuelve «entregar el flujo incremental de alta, ubicación, notificación, batch de conciliación, prueba y despliegue» con la solución más pequeña que funcione.
- [ ] **Paso 10.** Provoca el error «construir un monolito distribuido en carpetas sin propiedad clara de datos ni observabilidad» en un entorno desechable y captura la evidencia.
