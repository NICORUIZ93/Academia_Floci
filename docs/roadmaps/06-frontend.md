# Bloque 6: Frontend

Este bloque contiene 5 roadmaps independientes. Cada roadmap avanza en 30 pasos, desde cero hasta una evidencia de nivel avanzado; no presupone experiencia previa en el tema.

Los pasos 1–10 construyen fundamentos, 11–20 desarrollan práctica y diagnóstico, y 21–30 integran el tema en un resultado más cercano al trabajo profesional. Marca cada casilla solo cuando puedas mostrar la evidencia indicada.

**Contexto de práctica:** construir un tablero reactivo de tracking

**Conocimientos que conecta:** HTTP, observabilidad del usuario y arquitectura de componentes
