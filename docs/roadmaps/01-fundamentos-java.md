# Bloque 1: Fundamentos de programación y Java

Este bloque contiene 9 roadmaps independientes. Cada roadmap avanza en 30 pasos, desde cero hasta una evidencia de nivel avanzado; no presupone experiencia previa en el tema.

Los pasos 1–10 construyen fundamentos, 11–20 desarrollan práctica y diagnóstico, y 21–30 integran el tema en un resultado más cercano al trabajo profesional. Marca cada casilla solo cuando puedas mostrar la evidencia indicada.

## Tema 1: Fundamentos de programación

**Meta:** programa de consola con pruebas de caja negra

**Contexto de práctica:** calcular el precio total y el envío de un pedido

**Conocimientos que conecta:** algoritmos antes de elegir un lenguaje

### Pasos 1–10: nivel Principiante

- [ ] **Paso 1.** Describe el problema de industria «calcular el precio total y el envío de un pedido» y quién recibe valor de resolverlo.
- [ ] **Paso 2.** Escribe el resultado experto observable: programa de consola con pruebas de caja negra.
- [ ] **Paso 3.** Enumera lo que ya sabes y los prerrequisitos mínimos para estudiar fundamentos de programación.
- [ ] **Paso 4.** Define un glosario propio para las piezas de entradas, estado, decisiones, iteración y funciones.
- [ ] **Paso 5.** Dibuja el modelo, flujo o sistema físico de entradas, estado, decisiones, iteración y funciones antes de memorizar términos.
- [ ] **Paso 6.** Prepara Python 3 y terminal; registra versión, comandos y una forma segura de limpiar el laboratorio.
- [ ] **Paso 7.** Encuentra en Python Tutorial: control flow, data structures y functions una explicación oficial y anota qué conceptos confirma.
- [ ] **Paso 8.** Traza un caso exitoso de «calcular el precio total y el envío de un pedido» desde la entrada hasta el resultado.
- [ ] **Paso 9.** Resuelve «implementar un presupuesto con tres casos límite» con la solución más pequeña que funcione.
- [ ] **Paso 10.** Provoca el error «confundir asignación con comparación o ignorar el límite» en un entorno desechable y captura la evidencia.

### Pasos 11–20: nivel Intermedio

- [ ] **Paso 11.** Diagnostica el fallo anterior paso a paso; explica causa, síntoma y corrección, sin ocultar el error.
- [ ] **Paso 12.** Implementa la pieza central de entradas, estado, decisiones, iteración y funciones y sepárala de presentación/configuración cuando corresponda.
- [ ] **Paso 13.** Añade pruebas para caso normal, borde, entrada inválida y una regresión del fallo provocado.
- [ ] **Paso 14.** Compara dos enfoques para «calcular el precio total y el envío de un pedido» y registra un criterio medible para elegir.
- [ ] **Paso 15.** Especifica entradas, salidas, errores esperados y supuestos del componente de fundamentos de programación.
- [ ] **Paso 16.** Revisa validación, permisos, datos sensibles, unidades o seguridad funcional pertinentes a entradas, estado, decisiones, iteración y funciones.
- [ ] **Paso 17.** Introduce un fallo propio del dominio —por ejemplo entrada inválida, inconsistencia, pérdida de conexión o error de colaboración— y define cómo recuperarte.
- [ ] **Paso 18.** Mide una propiedad adecuada al problema —tiempo, calidad, error, consultas, recursos o esfuerzo— y conserva la línea base.
- [ ] **Paso 19.** Optimiza solo una limitación demostrada y compara la medición antes/después.
- [ ] **Paso 20.** Comprueba persistencia, reinicio, reproducibilidad o restauración del resultado «programa de consola con pruebas de caja negra».

### Pasos 21–30: nivel Avanzado

- [ ] **Paso 21.** Automatiza build, análisis o verificación del ejercicio para detectar regresiones al cambiarlo.
- [ ] **Paso 22.** Documenta una decisión técnica y enlaza evidencia primaria consultada en Python Tutorial: control flow, data structures y functions.
- [ ] **Paso 23.** Pide revisión a otra persona o usa una checklist; corrige un problema concreto de claridad o robustez.
- [ ] **Paso 24.** Completa un laboratorio autónomo que produzca «programa de consola con pruebas de caja negra» y guarda entrada, salida y pruebas.
- [ ] **Paso 25.** Evalúa el laboratorio contra criterios explícitos: corrección, casos límite, seguridad y evidencia.
- [ ] **Paso 26.** Conecta fundamentos de programación con algoritmos antes de elegir un lenguaje; dibuja el contrato entre ambos conocimientos.
- [ ] **Paso 27.** Diseña una parte del proyecto integrador para «calcular el precio total y el envío de un pedido» y registra dependencias y riesgos.
- [ ] **Paso 28.** Construye esa parte, ejecuta las pruebas y registra qué no cubre el entorno de laboratorio.
- [ ] **Paso 29.** Amplía hacia el nivel avanzado con una restricción real: escala, concurrencia, tolerancia a fallos o incertidumbre.
- [ ] **Paso 30.** Explica el sistema sin notas, defiende una decisión con evidencia y enseña a otra persona a reproducir «programa de consola con pruebas de caja negra».

**Criterio de salida:** entrega «programa de consola con pruebas de caja negra», explica «confundir asignación con comparación o ignorar el límite» y demuestra cómo fundamentos de programación se conecta con algoritmos antes de elegir un lenguaje.

**Fuentes primarias para iniciar:** Python Tutorial: control flow, data structures y functions.
