## Uso recomendado

Los [exámenes integradores por bloque](./evaluaciones.md) proponen una práctica verificable por tema y una rúbrica común; el examen final integra las 20 áreas en RutaFlow.

1. Empieza por los pasos 1–10 del tema elegido y reserva tiempo para ejecutar, no solo leer.
2. Conserva evidencias: código, pruebas, mediciones, diagramas, decisiones o notas de laboratorio.
3. Avanza a pasos 11–20 cuando puedas explicar el modelo y resolver el ejercicio inicial sin copiar.
4. Avanza a pasos 21–30 cuando diagnostiques fallos, compares alternativas y puedas integrar el tema.
5. Trata la meta como un objetivo de práctica deliberada, no como promesa de expertise instantáneo.

## Modo intensivo sin saltarse la práctica

Trabaja en sesiones enfocadas de 60–90 minutos. Lee únicamente lo necesario para ejecutar el paso actual; al final, cierra la guía y reconstruye la idea de memoria, revisa el error que más enseñó y guarda evidencia. Si ya demuestras un paso con un artefacto y una explicación, márcalo y sigue: no repitas contenido que ya dominas. Reserva los pasos de prueba, fallos y revisión; eliminarlos acelera la lectura, pero no el aprendizaje.

Las etapas se adaptan a cada dominio: un circuito usa simulación y medición; una API usa contratos y tests; una habilidad profesional produce decisiones y evidencia de colaboración. No se inventan circuitos del PDF ausente: los ejercicios eléctricos se identifican como ejemplos didácticos equivalentes.
