# Bloque 10: IA aplicada al estudio

Este bloque contiene 4 roadmaps independientes. Cada roadmap avanza en 30 pasos, desde cero hasta una evidencia de nivel avanzado; no presupone experiencia previa en el tema.

Los pasos 1–10 construyen fundamentos, 11–20 desarrollan práctica y diagnóstico, y 21–30 integran el tema en un resultado más cercano al trabajo profesional. Marca cada casilla solo cuando puedas mostrar la evidencia indicada.

## Tema 66: Prompting para aprender cualquier tema

**Meta:** ficha de estudio con preguntas, respuestas propias y fuentes comprobadas

**Contexto de práctica:** estudiar un concepto técnico y detectar si una explicación quedó superficial

**Conocimientos que conecta:** metacognición, documentación y práctica deliberada

### Pasos 1–10: nivel Principiante

- [ ] **Paso 1.** Describe el problema de industria «estudiar un concepto técnico y detectar si una explicación quedó superficial» y quién recibe valor de resolverlo.
- [ ] **Paso 2.** Escribe el resultado experto observable: ficha de estudio con preguntas, respuestas propias y fuentes comprobadas.
- [ ] **Paso 3.** Enumera lo que ya sabes y los prerrequisitos mínimos para estudiar prompting para aprender cualquier tema.
- [ ] **Paso 4.** Define un glosario propio para las piezas de esencia, analogía, descomposición, errores, preguntas, práctica y malentendidos.
- [ ] **Paso 5.** Dibuja el modelo, flujo o sistema físico de esencia, analogía, descomposición, errores, preguntas, práctica y malentendidos antes de memorizar términos.
- [ ] **Paso 6.** Prepara modelo de IA disponible y fuentes primarias; registra versión, comandos y una forma segura de limpiar el laboratorio.
- [ ] **Paso 7.** Encuentra en fuentes oficiales del tema estudiado y guía institucional de IA una explicación oficial y anota qué conceptos confirma.
- [ ] **Paso 8.** Traza un caso exitoso de «estudiar un concepto técnico y detectar si una explicación quedó superficial» desde la entrada hasta el resultado.
- [ ] **Paso 9.** Resuelve «pedir una explicación, resolver ejercicios sin mirar y comprobar afirmaciones» con la solución más pequeña que funcione.
- [ ] **Paso 10.** Provoca el error «confundir fluidez textual con comprensión o aceptar citas no verificadas» en un entorno desechable y captura la evidencia.

### Pasos 11–20: nivel Intermedio

- [ ] **Paso 11.** Diagnostica el fallo anterior paso a paso; explica causa, síntoma y corrección, sin ocultar el error.
- [ ] **Paso 12.** Implementa la pieza central de esencia, analogía, descomposición, errores, preguntas, práctica y malentendidos y sepárala de presentación/configuración cuando corresponda.
- [ ] **Paso 13.** Añade pruebas para caso normal, borde, entrada inválida y una regresión del fallo provocado.
- [ ] **Paso 14.** Compara dos enfoques para «estudiar un concepto técnico y detectar si una explicación quedó superficial» y registra un criterio medible para elegir.
- [ ] **Paso 15.** Especifica entradas, salidas, errores esperados y supuestos del componente de prompting para aprender cualquier tema.
- [ ] **Paso 16.** Revisa validación, permisos, datos sensibles, unidades o seguridad funcional pertinentes a esencia, analogía, descomposición, errores, preguntas, práctica y malentendidos.
- [ ] **Paso 17.** Introduce un fallo propio del dominio —por ejemplo entrada inválida, inconsistencia, pérdida de conexión o error de colaboración— y define cómo recuperarte.
- [ ] **Paso 18.** Mide una propiedad adecuada al problema —tiempo, calidad, error, consultas, recursos o esfuerzo— y conserva la línea base.
- [ ] **Paso 19.** Optimiza solo una limitación demostrada y compara la medición antes/después.
- [ ] **Paso 20.** Comprueba persistencia, reinicio, reproducibilidad o restauración del resultado «ficha de estudio con preguntas, respuestas propias y fuentes comprobadas».

### Pasos 21–30: nivel Avanzado

- [ ] **Paso 21.** Automatiza build, análisis o verificación del ejercicio para detectar regresiones al cambiarlo.
- [ ] **Paso 22.** Documenta una decisión técnica y enlaza evidencia primaria consultada en fuentes oficiales del tema estudiado y guía institucional de IA.
- [ ] **Paso 23.** Pide revisión a otra persona o usa una checklist; corrige un problema concreto de claridad o robustez.
- [ ] **Paso 24.** Completa un laboratorio autónomo que produzca «ficha de estudio con preguntas, respuestas propias y fuentes comprobadas» y guarda entrada, salida y pruebas.
- [ ] **Paso 25.** Evalúa el laboratorio contra criterios explícitos: corrección, casos límite, seguridad y evidencia.
- [ ] **Paso 26.** Conecta prompting para aprender cualquier tema con metacognición, documentación y práctica deliberada; dibuja el contrato entre ambos conocimientos.
- [ ] **Paso 27.** Diseña una parte del proyecto integrador para «estudiar un concepto técnico y detectar si una explicación quedó superficial» y registra dependencias y riesgos.
- [ ] **Paso 28.** Construye esa parte, ejecuta las pruebas y registra qué no cubre el entorno de laboratorio.
- [ ] **Paso 29.** Amplía hacia el nivel avanzado con una restricción real: escala, concurrencia, tolerancia a fallos o incertidumbre.
- [ ] **Paso 30.** Explica el sistema sin notas, defiende una decisión con evidencia y enseña a otra persona a reproducir «ficha de estudio con preguntas, respuestas propias y fuentes comprobadas».

**Criterio de salida:** entrega «ficha de estudio con preguntas, respuestas propias y fuentes comprobadas», explica «confundir fluidez textual con comprensión o aceptar citas no verificadas» y demuestra cómo prompting para aprender cualquier tema se conecta con metacognición, documentación y práctica deliberada.

**Fuentes primarias para iniciar:** fuentes oficiales del tema estudiado y guía institucional de IA.
