## Cobertura garantizada por el lector

Los 1.201 temas reciben en tiempo de ejecución una guía de cuatro pasos con ruta de archivo, ubicación dentro del proyecto, comando, resultado esperado y práctica. Cuando el Markdown no posee código, el lector añade un punto de partida específico para el lenguaje del track; cuando no posee diagrama, añade un mapa concepto → aplicación → evidencia.
